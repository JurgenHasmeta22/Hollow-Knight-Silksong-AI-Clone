# Bellweaver — "Chapter II" content expansion plan

Game root: the repository root (vanilla JS + Canvas, no build step, global `BW` namespace).

## 1. Goal

Turn the finished 1-chapter game into a much bigger one:

* **6 new, very different bosses** (≥5 requested) — parry / Shadow-Step based, many attacks each,
  medieval soldiers *and* monsters/animals.
* **Nightmare "execution" attacks:** each boss has 1–2 signature attacks that **kill in one hit on Nightmare**
  (long, loud, unmistakable tell; always answerable with a parry or Shadow Step). On Story/Action the same attack is just a heavy hit.
* **~35 new rooms in 6 new areas**, woven into the existing map Dark-Souls / Sekiro style: shortcuts, loops,
  one-way doors, lanterns as bonfires, non-linear boss order.
* **12 new enemy types** (soldiers + insects/animals), each with a readable tell and punish window.
* **Chapter I is "cleared" visually** (card after the Great Bell rings) and then play simply *continues*:
  the toll cracks seals all over the existing world.
* **Docs:** `docs/CONTENT_GUIDE.md` (how to operate + how to add maps/enemies/bosses), plus complete
  GPT-Image-2.5 prompt packs for sprites, backgrounds, props, UI, and music/SFX prompts, in the same visual style as the current art.

User decisions: execution attacks = signature moves only (not every hit); world = interwoven (Sekiro/Souls), not a separate act;
theme = soldiers + monsters + animals/flies; art = prompts for everything (+ placeholders so the game runs before art exists);
guide lives in `docs/CONTENT_GUIDE.md` inside the game folder.

## 2. What the code review found (these shape the plan)

| Finding | Consequence |
|---|---|
| Rooms are a DSL (`BW.defineRoom` in `world.js`) placed on a shared **world tile grid**; exits auto-link by adjacency (`checkExits`, `map.js links()`). | New areas = new room files at free world coords. No exit wiring code. Needs a validator (overlap, sealed edges). |
| Enemy knowledge is scattered over 5+ tables: `ENEMY_TYPES`, `ENEMY_NAMES`, `Difficulty.WEIGHTS`, `GROUND_H`, `Codex.BEASTS`, `XP`. | Adding 12 enemies this way is error-prone. **Introduce one `BW.registerEnemy()`** — also the key to a simple how-to guide. |

| Player has 5 bells max; `Player.hurt(dmg, srcX, opts)` checks parry (`opts.noParry`) and Shadow Step (`opts.strike`) *before* applying damage. | Execution = one `opts.lethal` branch **after** those checks → parry/dodge still save you; i-frames still apply. |
| Difficulty presets carry boss multipliers (`bossHp`, `poise`, `hitPoise`, `bossDmg`, parry 0.20 s on Nightmare, dodge reach 90 px). | Reuse as-is for all bosses; add `lethal: true` on Nightmare only. |
| Art is **pose sheets** (one static pose per frame, boss at `fps:1`) packed to `assets/manifest.js`, "generated by `production/tools/build_assets.py`" — **that tool is not in the repo**. Audio likewise (`build_audio.py`). | I must (re)create a packer: `tools/pack_sprites.py` + `tools/build_audio.py`, and an additive `manifest_ch2.js` so the 8.8 KB original manifest is never hand-edited. |
| `Assets.loadAll` decodes every image at boot. Adding ~6 areas + 6 boss sheets (~8–10 MB webp) hurts boot. | Add **asset groups** (lazy-load per area, preload on approach). |
| Missing sprite → `drawFallback` ellipse for enemies; unknown music id behaviour unverified. | Add proper placeholders (tinted reuse of existing sprites + shape-drawn silhouettes) and music fallback chain so every piece of content is playable *before* art/audio arrive. |
| XP caps at level 10 (1,530 XP); saves flat JSON, `SAVE_VERSION = 1`, migrations stubbed. | Raise cap to 15, bump save to v2 with a no-op-safe migration; all new progress is new flags → old saves load unchanged. |
| Dev hooks: only `?test=1` and Save Data → Test Saves. | Add `?room=`, `?boss=`, `?god=1`, per-boss test saves, and a fairness linter. |

## 3. Design pillars

1. **Tell colour language** (extends the existing gold PARRY / violet SHADOW STEP vocabulary):
   * **Gold glint** = parryable · **Violet glint** = Shadow-Step-only (cannot be parried: sweeps, grabs, shockwaves jumpable) ·
     **Blood-red sigil + red screen-edge pulse + low drone** = *Execution* (Nightmare: lethal). Red moves are *always* parryable **or** Shadow-Steppable.
2. **Fairness rules enforced by a linter** (`tools/fairness_lint.js`, run in `?test=1`):
   * non-lethal tell ≥ 0.45 s, lethal tell ≥ 0.75 s, recovery ≥ 0.5 s for the heaviest moves;
   * every attack declares `answer: 'parry' | 'dodge' | 'jump' | 'either'` and at least one boss move per phase is parryable;
   * no attack starts from < 0.4 s after the previous recovery ends.
3. **Every boss wins differently** (no clone of the Warden's poise bar): each has its own *break* mechanic — see §6.
4. **Non-linear order, soft gating:** areas gated by shortcuts, existing abilities (Dash / Parry / Shadow Step), flags and **Sigils** (see §5), never by a new mechanic. Dark-Souls loops: every area ends in a shortcut back to a known lantern.
5. **No engine rewrite.** Existing files stay; new content lives in new files so parallel work does not collide.

## 5. World design (interwoven, Sekiro/Souls style)

**Chapter I clear:** ringing the Great Bell → full-screen *"CHAPTER I — THE SILENT BELFRY · COMPLETE"* card (painted art), stats, then you are returned to the
Cathedral with the world changed (flag `ch1_clear`): the toll **cracks seals** — a hatch in Thornwood, a cracked wall in Rootfall, a lift stop in the Cord Lift,
a well in the Drowned Chapel, a gap in the Belfry ramparts. Odo hints at them. Existing endings/credits stay replayable.

**Sigils:** each of 5 area bosses drops a Sigil (`state.sigils`). The Underloom door under the Great Bell has 5 sigil sockets (Souls "Lordvessel" moment). Bosses can be taken in any order.

## 9. Art & audio pipeline (+ prompts you can paste into GPT-Image-2.5 / Higgsfield)

Style bible (derived from the current assets): hand-painted 2D, dark ink outlines, desaturated gothic-insect-folk, one luminous accent colour per area, soft rim light,
readable silhouette on a flat chroma-key background, consistent feet baseline, original designs. Boss = **12–14 pose sheet** (idle, walk, tells per move, strike, recovery, stagger, roar, fallen); enemy = 4–6 poses; backdrops far (parallax) + mid; tile texture 512² seamless; props on transparent.

Deliverables (written during implementation):

* `docs/ART_PROMPTS.md` — style-bible preamble + one prompt per asset: 6 boss sheets (every pose listed with the move it belongs to), 12 enemy sheets, 6×(far, mid, tile, 6–8 props), fog gate, sigils (6) + sigil sockets, drawbridge, banners, chapter card art, boss title plates, execution sigil glyph, codex portraits, ending art.
* `docs/AUDIO_PROMPTS.md` — 6 boss themes (+ phase-2 stems), 6 area themes, 6 ambiences, ~30 SFX (execution drone, arrow release/deflect, shield crack, water surge, siren, flail chain, etc.).
* Tools: `pack_sprites.py <sheet.png> <name> --poses ...` → crops by connected component, keys the background, anchors on foot baseline, outputs webp + manifest entries; `build_audio.py`.
* Until real art is generated, **placeholders** (tinted existing sprites + silhouette draw functions) keep everything playable; replacing art = drop file + run pack tool, no code change.

## 11. Verification

* `tools/validate_world.js` (room overlaps, unsealed edges, exit symmetry, lantern coverage) and `tools/fairness_lint.js` (tell/recovery minimums) — both required to pass.
* Warden regression: same test save, same hp/timings table before/after the base-class extraction.
* Playwright smoke (`runPlaywrightCode` / local server): load, enter each new room via `?room=`, spawn each boss, run a scripted parry/dodge bot through every attack in Action + Nightmare (lethal verified: unparried = death, parried/dodged = survive).
* Frame-time check in the heaviest new rooms (existing FPS counter); asset boot size check.
* Snyk code scan on new JS (workspace rule).

## 12. Risks / notes

* **Scope is large** → deliver as vertical slices: Phase 0 + Garrison/Aldric first, then areas in any order (files are independent).
* Warden extraction is the riskiest refactor; guarded by the regression table and kept behind identical tuning.
* Room coordinates in §5 are validated by the tool, not guaranteed by this plan.
* I cannot generate Higgsfield art/audio myself; prompts + packer + placeholders are the deliverable.
* Existing saves: unchanged behaviour; new content only appears after `ch1_clear`.
